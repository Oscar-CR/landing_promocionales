# PROMOSTORE 
Landing page premium para una empresa de **artículos promocionales personalizados**

![imagen proyecto](/img/promostore.png)

- **Enlace al repositorio en GitHub:** [https://github.com/Oscar-CR/landing_promocionales](https://github.com/Oscar-CR/landing_promocionales)

- **URL en vivo del sitio desplegado:** [https://landingpromocionales.vercel.app/](https://landingpromocionales.vercel.app/)


## Como correr el proyecto:

1. **Clonar el repositorio:**
    Clona el proyecto en tu máquina local usando Git:
    ```bash
    git clone https://github.com/Oscar-CR/landing_promocionales.git
    ```

2. **Acceder al directorio del proyecto:**
    ```bash
    cd landing_promocionales
    ```

3. **Ejecutar la aplicación:**
- **Opción A :** Puedes abrir el archivo `index.html` haciendo doble clic sobre él o arrastrándolo directamente a la ventana de tu navegador web favorito.
- **Opción B:** Utiliza un servidor local, o extensión como Live Server

## Documentación y Reflexión 
### Decisiones Técnicas
Dado a que es una aplicación sencilla, se optó por utilizar un html, css y js vanilla. Por la rapidez y facilidad para construir el sitio, además del tiempo. En caso de contar con más tiempo utilizaría alguna otra tecnología moderna, por la curva de aprendizaje que se requiere para aplicarla.

### Retos
El principal reto es trabajar con funciones nativas de javascript para la interacción, dado a que se trata de funciones vanilla y en muchas ocaciones estamos acostumbrados a trabajar directamente con librerias como Tailwind, que nos simplifica bastante la creación de estos componentes. Al finalizar con ayuda de la IA y documentación se pudo resolver y lograr el objetivo.

### Como usaste la IA
Utilicé opencode con el modelo KIMI K3 para pa construcción un PoC del proyecto base, primero construi el archivo de [`GUIA.md`](GUIA.md). como base de especificaciones y posteriormente construir el sitio, en algunos casos realicé interaciones para lograr un mejor diseño basado en mi criterio. Tambien Gemini para la creacion de algunas imagenes, como la persona del formulario. Para el resto de imagenes utilice figma y de forma manual las creé.
